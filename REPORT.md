# Лабораторная работа №3. Линейные модели: собственная реализация

## 1. Данные и их подготовка

### 1.1. Регрессия — Student_Performance.csv

Файл содержит 10 000 наблюдений и 6 столбцов. Целевой признак — `Performance Index`,
остальные пять — входные. Один из них, `Extracurricular Activities`, хранится как
строка `Yes`/`No`, поэтому я закодировал его вручную в бинарный вид: `Yes → 1`,
`No → 0`. Такое кодирование корректно, потому что у признака всего два уровня и
между ними нет порядка.

Далее я выполнил стандартизацию (Z-оценки) по каждому столбцу:
`x' = (x − μ) / σ`. Без неё признаки с разными масштабами (например, часы сна и
балл предыдущего экзамена) дают сильно разные по модулю градиенты, и пакетный
градиентный спуск начинает «прыгать». Стандартизация делает ландшафт функции
потерь более симметричным и позволяет использовать единый шаг обучения для всех
весов. Разбиение на train/test — 80/20, `random_state=42`.

### 1.2. Классификация — german.csv

Файл читается с разделителем `;`. Целевая переменная `Creditability` находится в
первом столбце и уже закодирована как 0/1. Остальные 20 признаков — числовые,
поэтому дополнительного кодирования не потребовалось; я лишь привёл их к float
и стандартизировал по той же схеме, что и для регрессии.

При разбиении использовал `stratify=y`: в исходном файле объекты отсортированы
по целевому классу, и без стратификации тестовая часть могла оказаться
однородной (только один класс), из-за чего ROC-AUC становится неопределённым.
Стратификация сохраняет пропорцию классов примерно 70/30 в обеих выборках.

## 2. Гипотезы и эксперименты

**Гипотеза H1 (регрессия).** Зависимость `Performance Index` от признаков
близка к линейной, поэтому обычная линейная регрессия, обученная полным
градиентным спуском, покажет MSE порядка нескольких единиц.

**Гипотеза H2 (классификация).** Данные german.csv разделимы логистической
моделью не идеально (признаки в основном категориальные, часто с нелинейными
эффектами), но ROC-AUC около 0.80 достижим.

**Гипотеза H3 (сравнение).** На табличных данных с преобладанием категориальных
признаков логистическая регрессия окажется не хуже дерева решений (которое
склонно к переобучению на малой выборке) и KNN (который страдает от
проклятия размерности при 20+ признаках).

### 2.1. Параметры обучения

| Модель | learning_rate | epochs | Инициализация |
|---|---|---|---|
| Линейная регрессия | 0.05 | 800 | веса = 0, bias = 0 |
| Логистическая регрессия | 0.10 | 1000 | веса = 0, bias = 0 |

Функции потерь: MSE — для регрессии, бинарная кросс-энтропия — для
классификатора. Градиенты выведены вручную:

- регрессия: `∂L/∂w = (2/n) Xᵀ(Xw + b − y)`, `∂L/∂b = (2/n) Σ(Xw + b − y)`;
- логистика: `∂L/∂w = (1/n) Xᵀ(σ(Xw + b) − y)`, `∂L/∂b = (1/n) Σ(σ(Xw + b) − y)`.

Шаг 0.05 для регрессии выбран как компромисс: при 0.1 MSE на первых эпохах
вела себя нестабильно, при 0.01 сходимость за 800 эпох не достигалась. Для
логистики 0.1 оказался устойчивым благодаря нормировке признаков.

## 4. Выводы

1. **Собственная логистическая регрессия практически совпадает со sklearn**
   (ROC-AUC 0.8081 против 0.8086, разница меньше 0.001). Это подтверждает, что
   аналитические градиенты выведены верно, а режим обучения (learning rate,
   число эпох) выбран корректно. По Accuracy, Precision, Recall и F1 значения
   совпадают в точности — то есть классификатор стабилизировался в том же
   оптимуме, что и эталонная реализация.

2. **Гипотеза H3 подтвердилась.** Дерево решений заметно проиграло
   (ROC-AUC 0.62): на 800 объектах обучающей выборки оно строит глубокое
   дерево и переобучается, а ROC-AUC — интегральная метрика, чувствительная
   к переобучению. KNN (0.75) оказался ближе к логистической регрессии, но
   всё же хуже: при 20+ признаках евклидово расстояние теряет
   информативность, и «соседи» становятся менее осмысленными.

3. **Линейная модель — адекватный базлайн для этих данных.** MSE ≈ 4.08
   означает, что типичная ошибка прогноза `Performance Index` — около 2
   баллов. Учитывая, что целевая переменная меняется в диапазоне ~10–100,
   это разумный результат для линейной модели без полиномиальных признаков.

4. **Кривая потерь ведёт себя ожидаемо:** монотонно убывает, без осцилляций
   и без «взрыва» градиента. Это косвенно подтверждает корректность
   масштабирования признаков.
